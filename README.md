# Orquídeas – Jardín Botánico del Quindío

Página de venta de orquídeas Phalaenopsis del Jardín Botánico del Quindío.
Regala naturaleza, regala vida.

## Archivos

| Archivo      | Contenido |
|--------------|-----------|
| `index.html` | Estructura de la página |
| `styles.css` | Estilos (colores y tipografías en `:root`) |
| `main.js`    | Lógica: productos, carrito, compra en 2 pasos, envío por Web3Forms y WhatsApp |
| `assets/`    | Imágenes, íconos y video |
| `LEEME.txt`  | Guía de configuración, seguridad y pendientes |

## Cómo verla

Ábrela con un servidor local (por ejemplo la extensión **Live Server** de VS Code)
o publícala con **GitHub Pages** (Settings → Pages → rama `main`).

## Configuración

Los datos editables están al inicio de `main.js`, en el objeto `CONFIG`
(precios, llave de pago, WhatsApp y llave de Web3Forms) y en la lista `PRODUCTOS`.
